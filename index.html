About me

I’m a Computer Science graduate (B.Sc., 2025) who enjoys turning ideas into working web applications. I build clean, responsive interfaces with HTML, CSS, JavaScript and React, and I’m growing into full-stack development with Node.js, Express and PostgreSQL.

UIDrop

A UI component library where developers browse, customize and copy components. Anyone can submit a component, and an admin approves it before it goes public.

  • Express REST API with Zod validation, rate limiting and a token-protected admin panel.
